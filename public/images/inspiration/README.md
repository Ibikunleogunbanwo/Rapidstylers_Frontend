# RapidStylers style inspiration

These images were generated for RapidStylers on 14 October 2026 and revised on 15 October 2026, using Black models and service-specific beauty prompts. The selected set varies clothing, settings, camera angles and lighting instead of using a repeated studio backdrop. Makeup, lashes, nails and barbering include service-in-progress scenes. They illustrate possible styles and are not photographs of work completed by a listed professional.

The demo gallery includes all 30 generated images and labels each one. The live homepage offers one inspiration image per gallery category. The live portfolio gallery continues to show approved professional uploads only. Do not reuse these images as customer testimonials, before-and-after results, professional portfolio submissions or evidence of a particular stylist's work.

The ten groups follow `src/utils/galleryCategories.js`, with three distinct images per group. The selection manifest and descriptive image text live in `src/utils/serviceInspiration.js`. Source generation files remain in the local Codex generated-images folder. The JPEG copies in this directory are optimized for small square gallery thumbnails.
