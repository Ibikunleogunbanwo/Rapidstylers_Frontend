## Which of these are stock

The `unsplash` and `pexels` filenames are licensed stock, not work by a
RapidStylers professional, which is the opposite of what Part 1 rule 5 of the
design brief asks for ("real team/product, not stock"). Ten of the 35 are in that
group: `g-locs-1`, `g-braids-5`, `g-braids-10`, `g-braids-11`, `g-braids-13`,
`g-braids-16`, `g-cornrows-3`, `g-nails-1`, `g-nails-9` and `g-nails-11`. They are
live in the gallery now; swapping them for the team's own photos is a one-line
change each.

## Adding the next batch

1. Review each photo — check for watermarks, another app's interface, and
   whether the subject can consent to being shown.
2. Normalise (downscale only; never upscale a small original):

```bash
python3 - <<'PY'
from PIL import Image, ImageOps
im = ImageOps.exif_transpose(Image.open("SOURCE.jpg")).convert("RGB")
if max(im.size) > 1400:
    im.thumbnail((1400, 1400), Image.LANCZOS)
im.save("public/images/gallery/g-new-1.jpg", "JPEG", quality=82, progressive=True, optimize=True)
PY
```

3. Add one line per photo to `CURATED` in `src/utils/curatedGallery.js`. The id
   must match the filename and start with `g-`; the category must be one of the
   twelve in the page's `CATEGORIES` list.
4. Run `npx vitest run src/utils/curatedGallery.test.js`. It fails if a file is
   present but unlisted, or listed but missing.
